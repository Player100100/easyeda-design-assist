# 原理图返工实测边界（2026-11-15）

本记录只描述 LM2596 画布返工所验证的范围，不能据此称执行器支持成熟的任意布局编辑。

- 器件位置修改会重置部分元数据；移动适配器显式保留 Supplier Part 及已有 Value/Voltage Rating/Datasheet。
- 网络标志 setter 曾清空 Name/Global Net Name；相关实验必须完整回读，不能只看坐标成功。
- 逐根平移导线会在中间状态产生自动合网。`translation_script` 已在调用 bridge 前拒绝 WIRE 平移。现有线组重建适配器仅用于已记录的本任务修复，不能当作通用自动布线。
- 重复文字隐藏不解决符号本体拥挤。本次保留 U2.3/U2.5 导线的 GND 网络名称，删除两只重叠的 GND 网络标志。保留反馈 5V_OUT 标志；全部器件和导线不移动。
- 原生删除会将后续记录 ticket 按实际删除数量压缩。校验器要求删除集合严格等于目标符号及直属 ATTR，并逐记录验证压缩后的 ticket、其他值、几何和身份；不是忽略所有 ticket 差异。每一步另核对原生22引脚网络。
- 第一只地符号的旧结果仍为 uncertain；独立取证后另写验证记录，不改写原失败日志。布局/属性返工锁禁止旧计划重放。
- `getCurrentRenderedAreaImage` 可能重复返回之前的画面，即使源已改变。PNG 文件取得成功不等于画布视觉核验成功；图像与源冲突时暂停写入，核对坐标与真实用户截图。本次曾误把缓存中的地符号判断成反馈标志，反馈删除在预检阻断、未执行；已停用相应试验脚本。
