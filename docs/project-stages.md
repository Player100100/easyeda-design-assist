# 项目级阶段工作指引

阶段是按证据推进的工作视图；允许回退。工具列出的资料齐全只表示记录可审阅，不代表设计正确或用户已经批准。

## framing

**目标：** 确认做什么、给谁用、在哪里使用、怎样判断有用。

**输入：** 用户场景，现有产品/设备，环境、成本、尺寸、数量、法规/安全要求和交付期望。正常启动、停止、异常和维护场景均考虑；未知保持 TBD。

**输出：** 范围与明确排除项；有来源的需求；每项需求的客观验收判据、优先级和验证方法；开放问题与假设。

**检查：** 需求描述结果，不预先指定实现；可量化或有明确检查方法；无互相矛盾项；高影响开放问题已向用户确认或风险化处理。来源、验收标准和范围的变更要保留记录。

## architecture

**目标：** 将系统需求分配至模块，先解决模块边界和互操作。

**输入：** 可理解的系统场景、需求、外部设备和限制。

**输出：** 方框图/功能路径、电源树、模块职责与需求分配；模块接口表（来源端、目的端、方向、额定/范围、时序、连接器/引脚、机械条件、未知值）；适用的功耗、热、尺寸、精度、时序等预算及余量。

**检查：** 每项必须需求至少分配至模块；内部连接两端定义相容；接口源/灌、极性、上电条件和故障状态清楚；预算使用同一工况并考虑容差、峰值与余量。注明不适用的预算及理由。

**评审：** 架构候选、权衡、重大风险、用户确认与淘汰理由。高风险/高不确定决策可先做计算、仿真或小试验，避免过早冻结。

## design

**目标：** 从模块规格细化到有来源、可实现并可检查的电路和物理约束。

**输入：** 已评审的模块/接口基线、关键预算和选择决策。

**输出：** 器件型号和封装身份、手册修订与引脚核对；信号/电源连接及外围；关键计算、容差和最坏工况；板框、叠层、制造能力、关键回路和布局约束；需求映射、风险、测试计划及有序任务。PCB 按 [约束先行、路径驱动、分层复查](pcb-design-method.md)形成板厂规则/网类、机械约束、功能分区、布局评审、关键路径布线与验证计划。

**检查：** 不从网名猜电压/方向；不从库字段推定保证参数；覆盖启动、负载、故障、温度和器件偏差中相关工况；需求可追溯到模块/决策/证据及验证计划；原理图和 PCB 变更同步。板厂与层叠规则先于布局；关键电流和回流路径须有依据，DRC 不替代热/EMC/阻抗/安规验证。

**评审：** 先完成可能推翻架构的高风险验证，再展开常规细节。明确器件供货、替代、封装/引脚和板厂能力的证据时间与适用范围。

## integration

**目标：** 确认模块的真实连接和边界在集成中一致。

**输入：** 完成的模块设计和当前工程快照。

**输出：** 更新后的 EasyEDA 原理图/PCB、网表/差异、接口对账、跨模块场景检查、集成缺陷清单和最新可制造输出候选。PCB 集成与修改使用 [PCB 设计方法](pcb-design-method.md)及[PCB playbook](playbooks/pcb.md)复核。

**检查：** 对账端到端电源、复位/使能、反馈/保护、通信方向、共地/隔离、连接器、关键几何和共享资源。保存快照标识与范围；API 采集不是原子冻结。接口或需求变化需重开受影响核对。

**边界：** ERC/DRC 与网表检查是局部检查；未覆盖的仿真、热、电流能力或 EMC 问题须显式保留。

## verification

**目标：** 按计划证明受控设计符合规格，并在真实使用情境中确认解决了原问题。

**输入：** 设计版本/导出文件标识，需求与验收标准，验证方法、工况、仪器/夹具和判定规则。

**输出：** 每项需求的分析、检查、演示或实测结果；原始数据/图片/仪器信息；失败、偏差和重测记录；用户需求确认记录。

**检查：** 把“符合规格”与“满足使用预期”分别记录。结构校验、API 成功、DRC 和网表比较不得冒充板级功能验证。测试记录关联具体板卡/固件/配置版本；变更后评估复测范围。

## released

**目标：** 交付可识别、可制造、可追踪的确定版本。

**输入：** 受控原理图/PCB 版本、已处理缺陷、验证记录、制造商当前能力。

**输出：** Gerber/钻孔、BOM、贴装坐标等要求的制造包；文件哈希清单、版本说明、制造参数、未解决风险与用户发布决定。

**检查：** 独立审阅输出层和钻孔、板框/层数、BOM/CPL 位号与文件版本一致性，确认板厂叠层/阻抗/规则和拼板要求；对制造包重新打开或重新导入复核。参考 [PCB 制造包与样板验证流程](pcb-design-method.md)。记录哪些规格是板厂确认，哪些仅按公开能力推定。交付包 hash 只能证明文件未变化，不能证明设计正确。
