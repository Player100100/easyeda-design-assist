# PCB 设计方法（研究版）

## 目标

针对小型单板到中等复杂度产品，采用以下主线：

```text
需求/工况 → 原理图/封装基线 → 板厂与层叠 → 板框/分区 → 布局评审
→ 关键回路布线 → 普通信号与铺铜 → DRC/网表/机械/DFM/必要仿真
→ 制造包复核 → 样板制造/装配 → 上电与实测 → 改版或正式发布
```

设计决策应绑定到三个方面：

- **约束**决定制造、装配、电流/电压和温升是否可行；
- **路径**决定电流、回流、噪声和阻抗如何经过真实铜层与器件；
- **证据**区分 CAD 观察、手册、计算、板厂能力、假设和实测。

DRC 通过不等同工程正确。DRC 主要发现几何与规则冲突，不能代替功能、EMC、热、阻抗、安规或实板验证。

这是对公开流程的综合方案，具体参数仍须由本板的工况、器件手册和板厂确认。机械、原理图、层叠和布局会相互影响；前期可并行探索，进入详细布线前应明确这些边界。简单整改只执行受影响步骤，无需重走整板流程。

## 阶段和交付物

### 1. 定义问题和边界

登记用途、尺寸、连接器、输入输出、功耗、环境、成本、交期、法规、启动/停止/故障场景和验收标准。将持续/峰值电流、允许温升、信号速率/边沿、阻抗、隔离和测试点写成可验证条目。未知值保持 TBD；对会改变布局的未知安排查询、计算或实验。

交付物：需求与工况表、机械约束、接口表、风险清单、验证矩阵。

### 2. 建立电气和封装基线

原理图先完成电源树、保护、反馈、时钟、复位、连接器和测试点。每个器件绑定完整制造型号、数据手册修订、符号、封装、焊盘编号、极性和高度；对 QFN/DFN 裸焊盘、连接器、开关、电感和变压器核对机械图。完成 ERC 后冻结一次网表和 BOM 候选。

交付物：原理图版本、封装核验表、BOM/供货状态、网表哈希、ERC 记录。

### 3. 先定制造和层叠

选择目标板厂和工艺后，依据其当前能力设置板厚、铜厚、介质、阻抗、线宽/间距、孔径、环宽、阻焊桥、铜到板边、表面处理和拼板。层叠要给高速/差分提供稳定参考平面并给功率和散热留出铜；此时就规划参考平面/铜区与禁止跨越的区域。比较两层与多层的成本、参考连续性和逃线能力，不默认所有板都用某一层数；无法满足则回到层叠和布局。

交付物：板厂能力快照、层叠表、阻抗计算/厂商确认、规则和网类表。

### 4. 板框、机械和功能分区

建立无自交、闭合的外轮廓，内开槽/挖空按板厂规则单独定义，加入安装孔、禁布/禁铜区、连接器方向、器件高度和散热器边界。把输入保护、电源变换、数字处理、模拟/参考、射频/高速和外部线缆按功能及噪声源/受害者分区；天线净空、保护器件到接口的泄放回路也要预留。分区依据是电流路径、回流和耦合。

交付物：板框与机械约束、功能分区图、关键器件相对位置草案。

### 5. 布局评审

先放机械固定件和连接器，再按能量流放置电源入口、保护、变换器、磁性件、滤波器和负载；按信号流放置驱动器、接收器、时钟、转换器和缓冲器。旁路/去耦紧贴对应电源脚，反馈和参考线远离开关节点，功率器件和热扩散路径连续。预留编程/调试、测试探针和连接器插拔空间。用飞线及网络邻接关系检查拥塞和回流可行性；必要时对 BGA/高速或电源热点试布线再调整布局，完成布局评审后再展开普通布线。

交付物：布局快照、关键器件位置理由、关键回路图、布局评审记录和待改项。

### 6. 关键回路布线

把每个高风险网络写成源、负载和返回路径。先预留载流、回流及隔离通道，再按不可绕行程度和风险排序：高 `di/dt` 电源回路、开关节点、差分/高速、采样时钟、ADC/DAC 输入、反馈和外部接口；没有适用于所有板的固定排序。电源铜同时检查温升、压降、过孔和连接器瓶颈；开关节点的面积兼顾噪声、热和电流。高速线保持参考平面连续并减少换层；同一 GND 参考体系换层时就近安排地回流过孔，参考从地变成电源平面时需另外分析回流耦合，不能靠一颗地过孔解决。差分对、阻抗、偏斜和终端按器件手册/接口规范处理。

交付物：关键网络路径表、线宽/过孔计算、阻抗或长度报告、局部仿真和风险记录。

### 7. 普通信号、回流和铺铜

参考平面和铜区已在层叠/布局时规划，布线过程中就要填充并检查关键回流。完成普通网络后重填全部铜区，检查孤岛、细颈、热焊盘、跨分割线、平面缺口、铜到板边和高压间隙；确认敏感线的返回路径没有被过孔、开槽或分割切断。热焊盘连接兼顾可焊性和载流，散热过孔兼顾导热与装配吸锡；隔离、天线等禁铜要求优先。

交付物：逐层铜区图、GND 连通性/孤岛检查、热焊盘与载流核对。

### 8. 综合验证

投板前完成原理图/PCB 网表和封装差异、ERC/DRC、未连接、板框和层映射、3D 高度/方向/装配、BOM/CPL、丝印和测试点检查。按风险追加信号/电源完整性与热分析、EMC/ESD 路径及爬电/间隙评审。DRC 例外逐项说明原因、规则、对象和证据；不能通过删掉约束掩盖问题。

### 9. 制造包、样板验证和发布

按板厂要求生成 Gerber、钻孔、板框、阻焊、丝印、钢网、BOM、贴片坐标、装配图和特殊工艺说明。用独立 Gerber/ODB++ 查看器或重新导入核对层、极性、孔、板框、开窗和拼板；确认制造商接受层叠、阻抗和特殊能力。保存文件哈希、版本、导出时间、板厂确认项、未解决风险和用户发布决定。

首次样板制造后，先检查装配、短路和电源轨，按电路确定限流、分电源域上电、时序、纹波、复位/时钟、功能、负载和温升测试顺序；再按验收需求做 SI/PI、EMC/ESD 等适用测试。限流值和仪器接法由该板额定值及测试计划确定。测试关联板卡、固件、配置和制造包版本，失败项回到受影响设计步骤。样板投产与通过验证后的正式发布分开记录。

## Agent 如何作出布局取舍

先满足机械、绝缘、额定值、制造及接口等约束，再处理不可绕行的关键路径和回流，其次优化拥塞、散热、装配/测试，最后整理对齐和外观。飞线最短、过孔最少是参考指标，不能取代这些约束。

存在明显冲突时，比较少量可行候选，写清变动的器件/网络、路径、噪声、热、成本和制造影响。例如两层方案无法保留关键参考回流时，应比较重新布局与增加层数，不一味增加跳线或切割地。缺少完整几何时先给相对位置和路由约束；没有坐标单位与层映射证据，不生成可直接执行的绝对坐标。

## 一次任务的最小记录

下表是设计记录建议，可放入现有 task/project 的说明与来源中，不新增 CLI 参数或强制建档要求。

| 记录 | 必填内容 |
|---|---|
| 目标和基线 | 板卡/版本、对象/网络、当前阶段、证据覆盖范围、预期结果 |
| 约束表 | 参数、值/单位、适用层/网类、来源与日期、假设/未知；不预填通用线宽 |
| 路径表 | 源端引脚 → 负载引脚 → 返回源；峰值/边沿、参考层、换层和敏感邻居 |
| 修改建议 | 器件相对位置或已核验坐标、走线/铜区变化、理由、取舍和影响对象 |
| 复查记录 | 修改前后证据、检查方法、判据、结果、未查项和待完成验证 |

局部任务按“定位 → 约束 → 路径 → 修改 → 复查”执行。封装、连接、叠层、机械边界或制造工艺变化时重开相关复核；没有变化的无关模块不要求从头建档。

## 设计策略的物理依据

### 电源回路优先

TI 的 DC/DC 布局实验把高 `di/dt` 回路和开关节点视为主要 EMI 来源：缩小回路面积、将输入旁路放在高频电流路径上、保持连续参考平面，通常比单纯改变走线拐角更有效。对开关节点还要限制铜面积和邻近耦合；滤波、阻尼或边沿控制需要同时检查效率、温升和稳定性。

### 连续参考和实际回流

TI 与 Analog Devices 的资料都强调低阻抗、低电感的地/参考路径。连续 GND 平面通常是默认方案；混合信号是否分区、AGND/DGND 在何处连接，要依据器件内部电流、系统拓扑和数据手册决定。先画回流再考虑分割，不能把切地当作通用降噪措施。

### 制造能力先于极限规则

KiCad 官方教程把层叠、约束和网类放在布局前，并要求原理图与 PCB 同步、布局后 DRC，最后输出 Gerber 和钻孔。Altium 的公开入门资料也把制造能力、规则、完整布局、布线和制造输出列成连续流程。JLCPCB 的能力页显示层数、阻抗、最小线宽/间距、孔、铜厚和阻焊受工艺限制且会更新；项目规则应引用当时确认的板厂页面，不写成永久固定值。

## 适用于本项目的交互方式

1. 用 `context`/`query` 读取工程和所选 PCB 图元，记录缺失字段、单位与层编号。
2. 在对应原理图页获得焦点后用 `schematic --save` 和 `inspect` 确认目标网络的真实器件和引脚，再按手册/工况识别驱动与负载；网表本身不证明方向、电压或 PCB 回流。
3. 用 `new-task --mode pcb` 记录工况、板厂、层叠、目标和未知项；区分 CAD 观察、手册事实、计算、假设和结论。
4. 输出对象、具体变化、工程依据、条件、取舍和验证动作。当前 PCB 修改由用户在 EasyEDA 完成；流程记录不代表已有 PCB 写入实现。
5. 修改后读取 PCB 选中对象，并从 EasyEDA 客户端另外取得 PCB DRC、未连接/一致性和视图/导出证据；如原理图也变更，再采其网表及原理图审计。`query --kind audit` 和 `compare-design-audits` 当前仅处理原理图，不能作为 PCB DRC 或完整 PCB 网表比较。各次采集记录文档/版本，证据范围不足时只报告局部结论。

## 当前项目边界

项目当前提供所选 PCB 元件、直线、过孔和铺铜的受限属性读取，最多取 100 个所选对象详情，保留截断、缺失与错误；没有完整 PCB 几何，单位/层映射尚未实板校准。项目不支持 PCB 器件放置、自动布线、铺铜、旧 PCB 对象移动/删除或 PCB 写入。原理图执行器的实测能力不能推导出 PCB 写入能力。绘制完成的结论须有对应版本的 EasyEDA 客户端检查、视图以及必要的制造或实板证据。

本方法是有来源的工作指引，尚需具体板卡验证；软件测试通过不表示 PCB 设计或真实制造已验收。
