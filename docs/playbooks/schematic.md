# 原理图局部辅助

以用户指定功能或疑问为范围，查询目标及相关网络、上下游器件、供电/参考和保护。核对实际型号手册中的引脚、电平、外围、时序与工作条件；检查未使用引脚、使能、反馈、去耦及故障回路时说明适用范围。

缺少负载、对端设备或工况时记录未知。将 CAD 事实与推断分开，给出具体应修改的连接及依据、局部影响和验证步骤。导出空网络不直接等于误接或悬空故障，需核对图元与设计意图。不要把局部检查称为全板审核。

## 绘制前

1. 先列出功能块、接口与相关引脚，按信号流向排布器件。常见是输入在左、处理居中、输出在右，电源在上、地在下。连接器、反馈和保护回路可以按电路实际调整。非空白页沿用原图的阅读方向，标出变更区及其与旧电路的接口。
2. **用框和标题划分模块。** 同页有多个独立功能块时，默认给每个模块加无填充的细框，统一线型、颜色和标题样式。标题放在框内左上角，简短说明功能，例如「24V 转 5V 降压」；有阅读顺序时可按顺序编号。框完整包住模块内的器件、走线和标注，给标题和跨框接口留出空间。已有成熟分区样式时沿用；单个局部改动可沿用现有边框。
3. **先对齐，再压缩。** 先给图纸边框、标题栏和旧电路保留空间，再按功能排成行或列。相邻列从同一顶线开始，同列框尽量等宽，模块间距和框内边距保持一致。高度按内容定，避免为凑齐尺寸留下大块空白。重复电路优先用同一方向、对齐引脚、等距排布；确实共用同一对网络的并联支路，可共用左右母线，清楚画出各支路接点。
4. **缩短走线，保住阅读路径。** 按引脚功能决定器件朝向，让相邻器件直接连接。走线保持水平或竖直，减少绕行、折点和不必要的交叉，有意分支优先画成 T 形并核对节点。远距离跨块连接可用明确的网名，先核对同名确实是同一网络，区分独立的电源域和地域。去耦贴近对应电源引脚，反馈走向可追踪。为位号、数值、网名和引脚名留出可读间距，不让压缩后的走线与文字、器件或标题栏相碰。
5. **在方案里记录版式和取舍。** 说明模块名、行列与对齐基准、接口方向、保留区和必要例外；非空白页只整理本方案覆盖的区域。可执行候选用 `prepare-drawing-execution` 的 `route_metrics` 比较：该指标只覆盖计划新增导线的长度（10 mil）、直角折点及不同网的内部交叉。连接正确、标注易读和图框净距优先于追求最短线。模块框和标题如需写入，应列入方案并核对当前适配器是否支持。

## 绘制后

在变更前后分别用 `drawing-svg` 归档同页原生 SVG。先看整页，核对模块框与标题是否一一对应、边线是否对齐、间距是否均匀，以及图纸边框和标题栏是否留净。再放大变更区及邻近的密集区域，核对走线、节点、符号朝向、网名、位号和数值。以下命令用证据 JSON 生成文字遮挡候选报告。

```powershell
python -B src/design_assist.py review-drawing-visual '<修改后SVG证据.json>' --before '<修改前SVG证据.json>' --save
```

报告用 SVG 坐标标记疑似重叠区，估算正交导线与单行文字的覆盖范围，列出遇到的未支持文字和导线格式。对比按文字位置和导线覆盖范围判断：旧线段的拆分或 ID 变化本身不会产生新候选，整块移位则可能把已有的遮挡报为新位置。不提供 `--before` 时列出当前页候选。模块框及标题的排版、实际字体、符号和文字间的遮挡仍需查看原图。使用网表逐引脚核对连接并比较详细 DRC；仅整理版式时，要求完整网表和详细 DRC 保持一致。分别记录视觉复核和电气核验结果。

## 实机示例

`Agent_test / P1` 的五个模块排成顶边对齐的两列：左列是两级电源，右列是三个实验模块。同列框等宽，R4–R7 等距竖排并共用两条母线，五个框均避开 A4 标题栏。导线段总长缩短约 33%，实机回读的 17 个器件的完整网表及 6 条原有详细 DRC 均一致。两列及其尺寸是该页的取舍，其他页按内容与保留区选用行列；此实验没有开放通用的已有对象重排适配器。
