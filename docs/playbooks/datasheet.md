# 按需查阅手册

先明确绘制者要查哪个参数、引脚、工况、应用图或布局要求。保留原件访问能力，使后续问题仍能回到整本手册；不把预生成的关键参数摘录当产品输出。

1. 从实际目标元件确认完整 MPN 和封装后缀，使用 CAD 手册链接作为线索，优先核对厂商原件及修订。
2. 用问题关键词或同义词搜索，再阅读完整页、相邻页、表头、脚注和图。扫描页仍可查看原页；搜索无命中不表示没有该内容。
3. 将用户的具体工作条件带入解释；区分绝对最大、推荐范围、测试条件和保证值。引脚复用及封装差异必须对应具体后缀。
4. 简明回答当前问题，引用原件、修订、物理页序和适用条件；没有依据就说明尚不能确定。无需为了简单查询强制生成长报告或填写全部任务字段。
