# PCB 设计与投板辅助

本指引采用“约束先行、路径驱动、分层复查”的方法。PCB 是原理图、电源/信号回流、机械结构和制造能力的共同实现，不只是把飞线连完。完整工作流和方法来源见[PCB 设计方法](../pcb-design-method.md)。

## 先判定目标和证据范围

明确任务是整板设计、模块布局、关键网络整改，还是投板前复查。读取当前工程、原理图网表和目标 PCB 文档，记录板卡实例、所选图元及采集范围；API 只读到选中对象时，不把局部结果写成全板结论。

原理图完成并同步 PCB 后，使用 `pcb-capture` 采集完整文档源、固定几何集合、全部器件焊盘、叠层/规则和详细 PCB DRC；`context` 仍只提供选中对象。API 坐标为 data-origin mil，单位、旋转和层映射在指定测试板验证后才用于写入。按 `full`、`partial`、`advice`、`layout-critical` 创建计划，步骤和参数见[PCB 自动化契约](../pcb-automation.md)。保留所有读取错误，不从原理图网表推断铜层回流。

- `full`：整板流程由 agent 分阶段推进。板框/机械固定件和布局完成后重新采集，再明确关键路径，最后处理普通网络、铜区和制造包。
- `partial`：只对明确的器件、网络和区域形成具体操作，范围外源记录与网络保持。
- `advice`：只给目标网络的端点、路径、层、回流、数值依据和验证动作，计划不得含写操作。
- `layout-critical`：完成指定布局及关键网络，把剩余普通网络和后续检查清楚交回用户。

计划由 agent 据实填入 `constraints` 和固定 `operations`，不用用户手工编写 JSON。`review-pcb-plan` 检查具体范围和原理图映射，`approve-pcb-plan` 记录真实认可，`execute-pcb-plan` 在该批范围内执行，无需逐步重复确认。当前 `4.1.100` PCB 适配器仍属实验能力；不得把该实现状态写成真实板卡已验证。

开始布局前登记会改变方案的输入：

- 电源输入/输出、持续/峰值电流、启动和故障工况；
- 信号方向、速率、边沿、差分阻抗、时钟和敏感模拟量；
- 板框、连接器、安装孔、器件高度、散热及爬电/电气间隙；
- 层数、板厚、铜厚、介质厚度、阻抗目标和回流参考层；
- 板厂、表面处理、最小线宽/间距、孔径、阻焊桥、铜到板边和拼板要求；
- EMC、ESD、安规、温升和测试点要求。

缺少会改变结论的输入时，先指出未知项并给条件化建议。不要从网名、默认规则或常见经验猜电压、电流、阻抗或回流路径。

## 四层板：先确定参考平面和层分工

四层板及两层升四层按[四层 PCB 设计指导](../pcb-four-layer.md)处理。以下要点随 `guide --mode pcb` 进入任务指引：

- 先取得板厂物理叠层，记录从顶到底的每层用途、铜厚、介质厚度、信号相邻参考和换层返回路径；编辑器显示四层不能证明这些条件已确认。API 层叠不可用时保留未知，使用独立制造依据。
- 对两面走线、多路供电且外层配电预算可满足的板，优先比较 `SIG+PWR / GND / GND / SIG+PWR`；采用 `SIG / GND / PWR / SIG` 时，逐项检查底层对电源区的参考及跨分区问题。选择取决于边沿、电流、布局和实际工艺，不固定套用一种叠层。
- 保护方案指定的连续 GND 层，普通自动布线层列表排除这些层；拥塞时先调整布局/出线，不为连通而直接占用参考面。信号换层安排就近回流过孔，GND/PWR 参考转换单独评审。
- 开关电源关键回路、去耦、晶振和载流铜按手册与工况布局；频率低不代表边沿慢，也不能从铜层数量推出阻抗或温升合格。
- 补线后重建全部受影响铜区，逐层核对实际填充、参考缺口、机械孔及过孔避让。分别报告连接/DRC、物理层叠和回流验收；`DRC=0` 只关闭对应 CAD 检查项。

详细层分工表、两层升四层的执行顺序、验收证据和来源见上述指导。这些属于 agent 的工程规划要求，现有程序预检不自动证明参考平面连续性。

## 个人开发者：高功率与高速板

个人开发可简化企业审批，将仿真集中在关键未知，专用设备按需借用或委托测试。设计仍需覆盖适用的额定值、故障工况、关键回路/回流、板厂层叠、制造包和样板验证。缺证据的项目标为“未验证/待外测”，注明受影响的使用范围。详细分工与验证分层见[个人开发者高功率与高速板方法](../pcb-design-method.md#个人开发者的高功率与高速板设计)。

- **高功率**：先核对电压、连续/RMS 与峰值/脉冲电流、占空比、电源可提供的故障电流/能量、启动/负载变化、环境和温升目标。沿完整供电及返回路径检查铜箔、过孔、焊盘与连接器的最窄/最热瓶颈，并估算压降、损耗、保护和热扩散；不使用脱离层叠与环境的固定线宽或“每个过孔可承载多少安培”结论。样板按定义的限流、分阶段上电、负载、测点与停止条件验证。
- **高速信号**：先依据边沿、布线电长度、接口容限和拓扑判断受控阻抗及时序需求。板厂确认实际材料/叠层上的阻抗规则；保持参考和回流路径，评估连接器、过孔、换层、端接、偏斜及电源噪声。按风险选择参考设计、计算、IBIS/SPICE、专项 SI/PI 分析或测量，不默认每个接口都要全波仿真。
- **功率与高速同板**：布局时评估开关节点耦合、大电流回流的公共阻抗和电源瞬态；联调在代表性负载跳变、功率级运行及目标接口速率下检查误码、掉链或功能判据。
- **能委托的事项**：阻抗叠层/试片、复杂热与 SI/PI 建模、EMC/ESD/绝缘等可按产品目标和剩余风险委托板厂或实验室。报告须绑定板卡版本、工况和判据；开发者仍负责确认覆盖范围并决定是否满足产品目标。
- **成本受限时**：优先复用边界匹配的厂商参考设计、成熟模块和测试夹具；必要时降低电流/速率、在接口允许时放缓边沿或分阶段做样板。降额条件写入设计记录，不能将降额原型的测试结论外推到额定工作点。

## 设计顺序

1. **原理图和封装基线**：核对完整制造型号、封装、焊盘编号、极性、散热焊盘和 3D 外形；完成 ERC，确认关键网、电源树、保护路径和测试点。原理图是电气连接的主来源，原理图修改后再同步到 PCB。
2. **制造约束和规则**：先选目标板厂和工艺，再建立层叠、阻抗、线宽/间距、过孔、铜皮、阻焊和机械规则。用网类区分高电流、电源、差分、时钟、敏感模拟、高压/隔离和普通信号；每个数值记录来源、适用层和裕量。
3. **板框、机械和分区**：建立闭合、不自交的外轮廓，内开槽/挖空按工艺单独定义；放置连接器、安装孔、开关、屏蔽和高度禁布区，预留天线净空及保护器件泄放路径。按功能和能量路径划分电源入口/保护、变换器、数字、模拟、射频/高速和外部接口区域；分区不能代替回流分析。
4. **先完成布局再布线**：先放机械固定对象和连接器，再放电源链路、功率器件、控制器、磁性件、滤波器和负载，最后放普通逻辑与接口器件。按真实连接和回流顺序排列；旁路电容贴近对应电源脚，保留编程、测试和装配空间。预先规划参考平面与铜区，必要时试走关键线检验拥塞，布局评审后再展开大规模布线。
5. **先处理关键电流回路**：对 DC/DC、LDO、马达、继电器和大电流接口画出工作状态下的闭合回路。高 `di/dt` 回路要短、宽、紧凑，输入旁路电容应直接服务开关回路；开关节点铜面积兼顾载流、散热和耦合，远离反馈、时钟、模拟输入和连接器。功率铜按电流、温升和铜厚计算，不能只按 DRC 线宽通过。
6. **按风险路由**：先预留载流、隔离及回流通道，再按不可绕行程度处理差分、时钟、ADC/DAC 输入、反馈、复位、高速接口和电源，最后普通网络。阻抗网络使用与层叠匹配的线宽/间距并保持参考连续；同一 GND 参考体系换层时安排就近地过孔，地/电源参考转换需另外分析回流。差分对约束和匹配按器件/接口要求处理。
7. **铺铜和回流**：沿用布局时规划的参考平面，在关键布线过程中就填充并检查回流，最后重填全部铜区。先确认回流再决定挖空或分割，不能仅因 AGND/DGND 名称机械分地。检查孤岛、细颈、热焊盘、载流、敏感区耦合、铜到板边、高压间隙和禁铜区；保留填充后的复核证据。
8. **逐层和逐网络复查**：检查板框、层映射、焊盘/孔、阻焊、丝印、器件高度、极性、连接器方向、测试点、散热和装配可达性。按关键网络追踪“源 → 负载 → 返回源”的完整路径，不只看某段线或局部 DRC。
9. **投板、实测和发布**：投板前完成 DRC、未连接/一致性、机械/装配及适用的仿真与工程评审；按板厂要求生成 Gerber、钻孔、BOM、贴片坐标等制造包，并独立打开复核。样板制造/装配后按计划限流上电、测功能/温升及适用的 EMC/ESD 等项目；失败回到受影响步骤。样板投产和正式发布分开记录版本、哈希、板厂确认及遗留风险。

上述顺序允许按工况迭代和回退，不是不可调整的布线优先级。简单局部修改只走“定位 → 约束 → 路径 → 修改 → 复查”，检查与该修改有关的往返路径和邻近对象。

## 关键设计判断

### 电源和开关电源

把输入旁路电容、开关管/控制器、整流器或低侧管、磁性件和输出旁路电容按电流环路摆放。对每个开关状态分别画出高频回路，缩小高 `di/dt` 回路面积；开关节点是高 `dv/dt` 噪声源，按载流与散热需要约束铜面积并评估邻近耦合，避开敏感线。必要时依据最坏输入电流和实测频谱设计输入滤波、阻尼或边沿控制，并复核效率、温升和稳定性。

### 混合信号和时钟

先识别真实的模拟回路、数字回路和转换器内部电流，再决定是否分区以及地平面在哪里连接。连续参考平面通常优于随意切割；任何分割都要证明返回电流不会被迫绕行。采样时钟、参考源和 ADC/DAC 输入按敏感模拟路径处理，数字总线、缓冲器和高扇出时钟远离这些区域；去耦电容到电源脚和参考地的环路要短且低电感。

### 高速和差分

在布局前定义阻抗、参考层、过孔数、长度/偏斜和连接器约束。先固定源端、负载端和层叠，再布线；不以长度相同代替阻抗、回流和拓扑正确。差分对跨层或跨参考区域时重新检查共模回流和阻抗，必要时用仿真或厂商计算器确认。

### 大电流、散热和安规

把持续电流、峰值电流、铜厚、允许温升、过孔阵列和散热器边界写成计算记录。高压或隔离网络同时检查爬电距离、电气间隙、槽孔、污染等级和连接器额定值；普通低压 DRC 不能代替安规判断。

## 变更、复查和停止条件

- 原理图、电源树、层叠、板厂能力、关键器件封装或机械边界变化时，重新评审受影响的布局、网类、回流和验证计划。
- 局部整改前后保留对应版本的 PCB、网表/一致性、详细 DRC 和视图证据；PCB 检查当前从 EasyEDA 客户端取得。`query --kind audit`、`compare-design-audits` 仅用于原理图；不要据此报告 PCB DRC 或完整几何已经检查。
- 只有目标、范围、规则和回读证据一致时才关闭任务；DRC 全通过、网表一致或 API 写入成功都不能单独证明功能、EMC、热或可制造性。
- PCB 适配器已有4.1.100局部[工具链实测](../pcb-live-verification.md)，具体方案认可后仍须显式实验开关。每批记录完整源、真实详细 DRC、回读参数与范围外对象；超时或未知状态保留日志和锁，不重试写入。原生整板布局在已布线/铺铜板阻断，铜区自定义边框/优先级未兑现参数拒绝。高功率/高速关键路径由 agent 按证据明确规划，普通自动布线只接收明确的普通网络。
