# PCB 布线与铺铜辅助

1. 明确目标网络及其电气角色，结合原理图核对实际连接、驱动和负载。读取所选 PCB 图元的属性，保留单位、层编号、缺失字段和错误。
2. 收集叠层、参考层、板厚铜厚、制造规则、电流、速率/边沿、阻抗、绝缘及温升要求。当前工具尚未提供完整 PCB 几何；需要时向用户取得布局/叠层证据，不能仅凭少量所选对象断言全路径。
3. 依据实际回流、关键环路、耦合与热路径提出走线/过孔/铺铜方案；数值建议写明输入与计算或厂商依据。铺铜考虑网络、连通性、回流连续、孤岛、热焊盘、载流与敏感区域，不默认越多越好。
4. 指出应检查的对象、层和路径，解释调整原因及取舍。用户绘制后重新读取并结合 CAD 视图/DRC、阻抗或热验证复查；没有几何证据时仅给条件化建议。
