# 按问题推荐功能拓扑

触发：绘制者询问某功能如何画、现有结构如何改进或如何补保护。

1. 查询现有接口、供电、负载、反馈及保护网络。列出必须保留的连接和可修改边界；新增功能先明确输入、输出、控制与参考地。不能从网络名推定规格。
2. 补齐转换目标、启动/关断行为、效率/精度/噪声、隔离要求、故障和环境条件。对会改变拓扑的缺项询问用户；先给带条件的概念候选也应标明假设。
3. 比较适用的两三种结构；有充分依据的唯一方案无需凑数。按输入范围、功率/带宽、控制复杂度、器件可得性、散热、EMI 和失效方式比较，引用厂商应用方案及其工况。
4. 给绘制者局部连接方案：端点→功能器件→负载，控制/反馈/补偿、去耦、参考地和保护回路；说明器件值如何计算、哪些值待手册核实。精确引脚号应核对具体型号，概念框图须标注不可直接作为最终原理图。
5. 检查启动浪涌、反接、回灌、开路、短路、掉电和控制异常中与本任务相关的情形。保护应说明威胁、阈值、能量、钳位与回流，不机械堆叠器件。
6. 输出绘制顺序、关键布局约束和仿真/台架验证动作。绘制后重读相连网络，检查新方案与已有电路是否冲突。
