# 按问题进行器件选型

触发：绘制者询问某处用什么器件、如何替换或如何确定参数。先定位该处在电路中的角色；不要直接按关键词给型号清单。

1. 查询目标及相邻网络，再定点查询供电来源、驱动端、负载和保护器件。记录现有器件型号、引脚连接和共享电源/接口的限制；新增位置则从待连接端点开始。
2. 建立约束表：工作/瞬态电压、持续/峰值电流、启动/关断/故障、温度、功耗与散热、带宽/精度/时序、封装引脚、板空间、成本与供货。每项注明用户输入、CAD 来源、手册或未知；电路连接本身不能给出负载电流。
3. 按器件角色查相应原文。例：MOSFET 看实际驱动电压下的导通电阻、SOA、栅电荷与热；稳压器看输入范围、压差/占空比、稳定性与电感电容要求；运放看共模、输出摆幅、噪声、稳定性和负载。示例只是查证方向，不是默认要求。
4. 用最坏工况、容差、降额和热边界筛选，再用同一约束比较候选。供应商库存/价格应带查询时间；没查到就标未知。不要把库属性直接写成保证值。
5. 返回推荐理由、替代候选与取舍、关键计算、封装/引脚核对状态、所需外围与绘制位置。说明是否可替换及仍需何种验证，引用目标、邻居、网络和手册页。

输出至少能回答：为什么适合这段电路、受哪些其他元件约束、如何连接、哪些条件下不能用、如何验证。
