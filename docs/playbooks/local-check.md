# 局部修改复查

记录修改前后版本、目标与预期变化。分别采集快照，比较器件型号/值、引脚连接和受影响网络；不要跨版本合并同名网络后当作同一事实。

用 `query --kind audit --save` 分别采集原始网表/详细 DRC，`compare-design-audits ... --save` 保留输入字节并比较组件/引脚网络与规则/图元身份。同样数量可能属于不同问题，缺少稳定身份时保留未匹配。`drawing-feedback` 可生成执行后的独立复核清单；源稳定不证明派生结果刷新，差分无回归也不自动判为写后或工程通过。用法见[差分与反馈](../audit-and-feedback.md)。

涉及原理图版式时，按[原理图绘制指引](schematic.md)复查整页分区、模块框与标题、对齐及净距，并放大变更区域核对标注和走线。仅整理版式时，独立确认完整网表和详细 DRC 保持一致。

沿实际连接检查上下游兼容、共享电源、反馈、启动/关断和相关保护。按任务需要复查 PCB 回流/布局与手册约束。列出已查范围、未查项、变化影响及可执行验证；证据不足的结论保持待定。冻结版本的完整审核仍交由审核项目独立执行。
