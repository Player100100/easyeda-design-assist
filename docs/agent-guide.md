# Agent 辅助绘板指引

本项目为 agent 提供工程思路与信息获取工具，弥补辅助绘板时的方法缺口。推理由 agent 围绕绘制者的问题完成；模式是工作指引入口，不是自动选型或自动拓扑引擎。先读取本指引，再读取对应 playbook。

PCB 任务使用[PCB playbook](playbooks/pcb.md)，复杂整板设计再读 `docs/pcb-design-method.md`（[方法与来源](pcb-design-method.md)）：先确定制造/层叠与机械约束，再按电源、信号及返回路径布局和布线，投板前独立核对制造包，样板回来后实测。局部任务只走相关步骤。当前没有 PCB 写入和完整几何，原理图 `audit` 不能代替 PCB DRC。

## 从问题到绘制建议

遇到整板/复杂功能设计，先用[项目级设计框架](project-design.md)和 `project-guide --stage <阶段>` 建立需求、模块接口、预算、风险和依赖任务；再对局部任务采用下面的方法。递归分解到每项任务都有明确输入、产物和验收判据；高风险未知先安排查证、计算或原型试验。跨模块共享的电源、地、时钟、复位、启动/故障状态必须作为接口或约束记录，不能只按元件列表拆任务。每次集成和变更后回到项目级核对，不以所有局部任务完成推定系统通过。

1. 用一句话复述用户希望解决的问题，定位目标位号、引脚、网络或待新增功能。没有现成器件时，从接口和预期连接边界定位，不强求先有选中对象。
2. `status` 查看连接；`context` 读取当前选择与元件属性。多个窗口必须指定 `--window-id`。`schematic --save` 读取一次网表；`inspect <快照> --designator U1 --depth 1` 查看目标与相邻器件，或用 `--net` 查询精确网络名。位号有歧义时用网表中的 `--component-id`，它不承诺等同于画布图元 ID。
3. 沿实际引脚连接识别供电来源、上下游接口、负载、反馈、保护和参考地。边界元件的其他网络尚未展开时继续定点查询；不要无条件沿 GND 展开整个工程。连接并不证明信号方向，网名不能证明电压或功能。记录快照路径、哈希、时间和分析范围；不跨快照拼接同名网。
4. 将信息列为 CAD 观察、厂商依据、用户约束、计算、推断和未知。库属性是线索，不能代替厂商手册。对会改变方案的缺项优先提问；可独立完成的分析继续进行。
5. 按问题查资料：从网表 props.Datasheet 或所选元件 OtherProperty 中寻找手册链接，核对完整型号、厂商及修订。链接可交给当前 agent 的网页/PDF工具访问；本 CLI 不自动联网下载。需要稳定复查时 `import-datasheet` 保留本地原件；`datasheet-search` 定位、`datasheet-page` 阅读完整页，图表用 `--render` 查看原页。不要为了形成报告而预先摘录整本手册。
6. 计算最坏工况，写出公式、单位、输入来源及裕量依据；区分典型值、保证值、绝对最大额定值和推荐工作范围。使用相同工况比较可行方案，说明取舍及不适用条件。
7. 输出可操作的绘制方案：目标位置、器件角色、具体连接、值或选值范围、局部布局约束、风险与待验证项。未核对的引脚号和数值保持待定，不把概念方案写成可直接照抄的最终电路。
8. 用户明确要求辅助绘制时，按 `docs/autodraw-policy.md` 先输出具体方案并等待认可；认可后允许在方案内完成操作，无需逐项重复询问。方案外变化、目标文档变化或影响结论的新信息出现时先暂停并更新方案。v2 器件放置已通过单器件实测；v3 实验性支持空白原理图的器件、网络标号和导线，契约和限制见 `docs/circuit-executor.md`。v3 尚未实机验证，不根据模拟测试宣布画布完成。绘制后检查受影响连接、工况和保护路径；仍需冻结版本独立审核。

## 建议记录

简短查询可直接回答问题并附原件页码；复杂任务用 `new-task --mode ... --goal ...` 生成带本指引的 brief。建议写明已知条件、依据、推导、可绘制方案、风险、未知和验证动作。用 task.sources 的来源 ID 关联建议；页码使用物理页序并说明修订。只引用实际核对过的内容，`reviewed` 不等于工程设计已验证。

## 常见失误

- 只看目标元件，不看驱动端、负载端和已有保护；凭网名判断功能、电压或可共地。
- 将引脚数相同、封装相近或供应商推荐当成直接替换依据。
- 把绝对最大值当正常工作值，把标称电容当偏压下有效电容，把典型曲线当保证性能。
- 只推荐 TVS/保险丝等名称，却不检查故障能量、钳位电压、承受能力和回流路径。
- 把原理图网络关系当成 PCB 几何、回流或阻抗证据；把 DRC 通过当成工程正确。
- 在部分网表、截断结果或过期上下文上声称检查了全板。
