# 四层 PCB 设计指导

本指导用于四层板的设计、两层升四层，以及已有四层板的局部整改。与 [PCB 设计方法](pcb-design-method.md)、[操作指引](playbooks/pcb.md)及[自动化契约](pcb-automation.md)配合使用。先确定层的职责、物理距离和返回路径，再安排布局和走线；增加两个布线层并不能直接证明参考平面、阻抗和回流满足要求。

## 开始设计前取得哪些信息

| 输入 | 要记录的内容 | 对设计的影响 |
|---|---|---|
| 电源与负载 | 电压范围、持续/RMS/峰值电流、负载变化、故障能量、允许压降和温升 | 决定配电铜宽/面积、过孔、散热，以及是否需要独立电源层 |
| 信号 | 驱动/接收器、最快边沿、长度、拓扑、接口要求、差分/阻抗/时序指标 | 决定参考层、端接、换层和长度/偏斜约束；不能只看时钟频率或波特率 |
| 制造叠层 | 板厂、叠层编号/修订、总板厚、每层成品铜厚、三段介质厚度、材料/Dk及适用频率、公差 | 决定实际耦合、阻抗、载流和加工规则；板厂未确认的候选保持为假设 |
| 机械与封装 | 连接器、安装孔、定位孔、槽、隔离、天线净空、禁布/禁铜、装配和散热空间 | 决定哪些区域不能走线/铺铜；封装内机械孔也须纳入 |

编辑器的四个铜层、真实材料叠层和每层的电气用途分别记录。API 层号不等于物理顺序或层用途，必须与目标文档实际层表核对。API 不能读取物理叠层时，保留错误并引用板厂资料或独立确认；`complete=true` 只表示对应几何读取完成。

## 选择层分工

下表的 L1–L4 指从顶到底的物理铜层，`SIG` 为信号，`PWR` 为供电铜区或平面。没有适合所有电路的唯一叠层。

| 候选叠层（L1 / L2 / L3 / L4） | 适用条件 | 需要评审的取舍 |
|---|---|---|
| **SIG+PWR / GND / GND / SIG+PWR** | 两面均有数字走线、多路供电且外层配电可满足电流/压降/热预算的控制板 | 两面信号分别紧邻 L2/L3 地参考；电源使用外层宽铜及局部铜区，需为其预留空间 |
| **SIG / GND / PWR / SIG** | 独立电源层有明确价值，或采用工况和叠层匹配的参考设计 | L1 通常参考 L2 地；L4 通常邻近 L3 电源，必须检查电源分区及其到地的高频返回路径 |
| **GND / SIG+PWR / SIG+PWR / GND** | 有外层屏蔽需求，且器件焊盘、出线及机械约束允许维持外层参考连续 | 两内层参考相邻外层，需评估内层串扰和外层焊盘/出线造成的地缺口；不能把普通外层碎铜当完整参考面 |

对同时需要两面走线、外层配电可行的个人 MCU/多路电源板，优先比较第一种候选；高电流或高速工况仍需按手册、制造能力和预算重新选择。四层无法兼顾参考连续性、出线和载流时，应比较重新布局或增加层数，不为连通而占用已指定的地平面。

第一种候选的具体职责如下：

| 物理层 | 布局/布线职责 | 参考与约束 |
|---|---|---|
| L1 顶层 | 器件、短距离关键信号、去耦、晶振、开关电源关键回路及适用的电源铜区 | 信号参考相邻 L2；开关节点面积、下方铜及禁铜按具体器件手册评审 |
| L2 内层1 | 连续 GND 平面 | 保护关键线下方参考，不用作普通信号绕线；检查槽和过孔反焊盘是否连成缺口 |
| L3 内层2 | 连续 GND 平面 | 为 L4 提供参考；在信号过渡、去耦和接口等需要处与 L2 通过地过孔连接 |
| L4 底层 | 信号、接口扇出、辅助器件和适用的配电铜 | 信号参考相邻 L3；电源区域不能挤掉必要走线、装配和回流空间 |

若采用第二种候选，方案必须说明哪些底层网络允许参考 L3、电源分区边界在哪里、换层时回流如何进入地。不得把多路电源拼成的分区层当作所有底层信号的连续参考。

## 物理叠层与规则

1. 选择板厂可制造的叠层，并把设计层映射到该叠层。外层信号与相邻参考平面间距会影响阻抗和回流分布；总板厚相同不代表阻抗相同。
2. 对有指标的网络，使用该叠层的铜厚、介质距离、Dk、阻焊及走线结构计算线宽/间距，并由板厂确认。没有阻抗指标的网络也要检查参考和边沿，不机械套用 50Ω、90Ω 或固定线宽。
3. 层数增加不会自动提高载流能力。逐段核对电源/地的铜厚、细颈、焊盘、连接器及过孔阵列；不把外层铜厚套到内层，也不固定假定每个过孔的载流量。
4. 常见四层工艺具有薄外侧介质和较厚中间芯板，L2/L3 不一定紧密耦合。不能仅凭一层 GND 邻接一层 PWR，或两内层都为地，就声称平面电容足以替代器件去耦。

例如 2026-11-22 查阅的嘉立创 `JLC04161H-7628` 页面配置中，外层铜为 0.035mm、内层铜为 0.0152mm，外侧介质为 0.21040mm。这只是所查配置的示例，不能写成项目默认值；其他铜厚、板厚和叠层编号均需重新核对。[来源 F4]

## 布局、供电和返回路径

- **先布局再展开普通布线**：先放机械固定对象、接口和电源关键器件，再放 MCU、晶振、去耦及辅助电路。根据真实焊盘规划出线；细间距器件应先试布关键通道，避免普通信号围住剩余引脚。
- **开关电源**：按每个开关状态画出完整电流环路，使输入旁路和高 `di/dt` 回路短而紧凑；控制 SW 节点面积，反馈从正确取样点返回，远离 SW 与磁性件。优先核对具体器件的推荐布局；地平面不能补救过长的关键回路，也不统一规定所有 SW 下方必须铺铜或必须挖空。
- **去耦与地**：电源脚、电容和地平面之间形成短的供电/返回环路，地过孔靠近电容地端。并联过孔的数量及位置兼顾电感、孔间距、反焊盘造成的平面缺口和装配工艺。
- **信号参考**：沿整条信号检查相邻参考铜的实际连续性，包括焊盘扇出、连接器、机械孔、分割、过孔阵列及铜区细颈。GND 的直流连通不能单独证明高频返回路径合理。
- **换层**：L1/L4 信号转换且参考分别为 L2/L3 GND 时，在信号过孔附近提供连接两地平面的回流过孔；核对其实际层连接和距离。若参考从 GND 变成 PWR，地过孔不能直接把两个参考网连接起来，需评审适当的电源到地去耦及过渡路径。
- **功能分区**：通过器件位置、供电路径和信号方向控制功率、数字和敏感模拟的相互影响。不要仅按 AGND/DGND 网名分割地；跨隔离边界的铜或电容必须遵循器件和系统要求。

地过孔距离、线间距和并行长度由接口、边沿、层叠及制造条件确定。TI SLLA414A 第 8 页在其高速接口场景给出回流地过孔与信号过孔中心距不超过 200mil，并强调越近越好；该值不作为本项目通用目标或所有信号的验收上限。[来源 F2]

## Agent 执行顺序和记录

1. **形成方案**：读取原理图/PCB 基线，为每层写清物理位置、材料依据、用途、允许网络、参考网/层、禁布和必要过渡。两层升四层时先重做这份表，再修订布局和路径。
2. **划定布线范围**：普通布线只能使用已声明的信号层和网络。指定为连续 GND 的层不进入普通自动布线层列表，不在拥塞或失败后自动放开；候选失败先复查布局、出线和叠层。
3. **检查关键路径**：保留电源/敏感网络的端点、宽度/面积、返回路径、参考层和换层位置的依据，再处理普通连接。绘制模式沿用已有具体方案和授权范围，不新增逐操作确认。
4. **重建和回读**：铜区轮廓与实际填充分开核对。临时移除填充用于补线后，要重建全部受影响铜区，确认无孤岛、细颈或参考缺口，再运行详细 DRC。
5. **逐层评审**：对照声明用途检查新增铜是否侵入参考平面。平面需要为信号让路时，回到方案评审；在已布满线的内层补铺 GND 不能自动恢复完整参考。
6. **分别交付证据**：给出 CAD 连接/DRC、物理层叠、关键回流、载流/热、适用的阻抗/时序，以及制造/样板验证各自的结果与缺项。Gerber 层数、CRC、网表一致和 DRC=0 均不能单独代表工程验收。

计划记录可以放入现有的 `stackup_evidence`、各网络的 `return_path`、`reference_transitions` 及方案理由，详细表以文件引用保留。它们属于 agent 的规划和复查要求；当前预检不自动判定平面连续性、阻抗和物理回流，不要求通过填写未实现的新字段来宣称通过。

建议每块四层板至少保留下面的逐层表，并对关键网络另附路径记录：

| 物理层/实际 CAD 层 | 铜厚与相邻介质依据 | 用途/参考网 | 允许网络/禁布 | 回读与填充视图 |
|---|---|---|---|---|
| 按当前板填写 | 已确认值或候选来源，未知保持未知 | 信号、供电或参考及其相邻层 | 本方案的具体范围 | 对应快照/层图与复核结论 |

## 本项目测试案例的适用边界

`Agent_test_stm32` 在 2026-11-22 的工具链测试中完成 95×85mm 四层板、53 器件、237 焊盘和详细 DRC=0。交付快照的 Inner1/Inner2 分别含 230/91 段走线，GND 铜区在顶/底层，物理叠层读取不可用。该案例证明了指定 CAD 工具链的执行结果；尚未证明外层 GND 参考连续性、物理叠层、SI/PI、热或 EMC，不作为上述连续内层地方案的验收样板。走线段数或过孔数本身也不能判定工程质量。

同日用户委托重构后，双内层 GND 候选未闭合全部普通布线，最终采用 `SIG+PWR / GND / V3V3 / SIG+PWR`：718 段走线全部在顶底层，231 个过孔，四个铜区重建，详细 DRC=0。实际 Gerber 中两内层分别形成一片连通主铜面，面积约占板面积的 92.4%/91.3%；原理图、器件位置和原有 PCB1 保持。证据位于外部数据目录 `pcb-refactor/2026-11-22-sgp/`。这证明层用途整改和 CAD 闭环；底层对 3.3V 的参考、换层去耦路径、物理叠层与 SI/PI/热/EMC 仍须独立评审，不能将铜面连通面积当作高速返回路径已验收。
